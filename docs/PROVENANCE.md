The ZIP `vm-unet-main (1).zip` contains two additional Python files (`train_new.py`, `datasets/dataset_new.py`) compared with `vm-unet-main.zip`. It is used as the broader supplied archive, not assumed to be a verified final submission. Cache bytecode and the upstream paper PDF are omitted; upstream licensing is retained. The scope evolved from classification in the proposal to segmentation in the code/report. Team members are documented; equal contribution has not been confirmed for this three-person course project.
